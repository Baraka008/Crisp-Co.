# Crisp & Co.

A responsive restaurant-brand landing page created as a companion concept to [crisp-co-app](https://github.com/Baraka008/crisp-co-app).

## Run locally

This is a static HTML/CSS/JavaScript site. Open `index.html` directly or serve the folder with any static file server.

## Current scope

- Responsive landing page with mobile navigation
- Menu concept cards and brand story sections
- Reduced-motion support and keyboard focus styles

The menu items are illustrative. This repository does not process orders, accept payments, or publish verified restaurant hours or location details. Connect it to the companion app only after the restaurant details, menu, seller authentication and backend security have been verified.

## Deploy

Suitable for Vercel static hosting. No build command is required; use the repository root as the project root.
